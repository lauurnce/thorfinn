# Setup

Do these in order.

- [ ] Connect your email, calendar and chat to the account the council will run under.
- [ ] Share any work or team calendars into your main calendar (See all event details).
- [ ] Turn on email notifications from your school's learning platform, and forward any other school or work notifications into that inbox.
- [ ] Share with the connected account: the studies and work folder, the venture folder and tracker, the group folder, the finance sheet (as Viewer) and the health log.
- [ ] Create the council hub Sheet with tabs: Index, Leif (with a Capture column), Einar, Askeladd, Thors, Canute, Thorkell. Put every file link on Index.
- [ ] Create the council report Doc with a README tab. Paste the README text and your emblem images.
- [ ] If you lead a group, create a task tracker Sheet (owner, task, due date, status) and a leader's log Doc in the group folder.
- [ ] If you manage group funds, decide where they live and link the sheet in the Charter.
- [ ] Fill in the bracketed context in each member's prompt.
- [ ] Replace every [LINK] and other placeholder in the Charter, then paste the Charter into the Project instructions.
- [ ] Create the Project in Claude itself, not from a local folder, so tasks run remotely.
- [ ] Create the six scheduled tasks with the prompts in `members/` and the times in `SCHEDULE.md`. Set Canute to an approval mode for the first two months.
- [ ] Log today's row in the health log so Thorkell has something to read on the first run.
- [ ] After the first week, read every tab and the briefs, and trim any prompt that produced noise.
- [ ] Drop any member you don't need. The council works with fewer seats.
