# Hub Sheet

One Google Sheet holds the council's working memory. Each member writes only to its own tab, newest entry at the top. Leif reads every tab each morning.

## Tabs

| Tab | Written by | What it holds |
| --- | --- | --- |
| Index | Me | Every file link the council uses: report Doc, health sheet, data room, ILPP folder, Lead Tracker, Outreach Record, ADI folder, AWS group Drive, Director Tracker, Captain's Log. |
| Leif | Leif | Run entries, plus the commitments list (new, done, overdue). Has a **Capture** column where I jot commitments myself; Leif moves each one into the list with a due date. |
| Einar | Einar | Run entries, the **Deadlines** table (subject, item, due date, status) and the **Work** table for ADI tasks and deadlines. |
| Askeladd | Askeladd | Run entries, with the full ILPP scoring table below each one. Also where I log ZVV hours if no Upwork summary arrives. |
| Thors | Thors | Run entries covering KPIs, event countdowns, director follow-ups and recruitment. |
| Canute | Canute | Run entries, with the monthly money summary below each one. The only place Canute ever writes. |
| Thorkell | Thorkell | Run entries, with the coming week's three-line plan below each one. |

## Tab entry format

From the charter. Each run appends one entry at the top of the member's tab:

```
Run: YYYY-MM-DD HH:MM
Status: green / yellow / red
Findings: 3 to 5 lines, most important first
Next step: one line
For Leif: one line, or "none"
```
