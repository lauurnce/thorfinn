# Hub Sheet

One Google Sheet holds the council's working memory. Each member writes only to its own tab, newest entry at the top. Leif reads every tab each morning.

## Tabs

| Tab | Written by | What it holds |
| --- | --- | --- |
| Index | You | Every file link the council uses: report Doc, studies and work folder, venture folder and tracker, group folder, task tracker and leader's log, finance sheet, health log. |
| Leif | Leif | Run entries, plus the commitments list (new, done, overdue). Has a **Capture** column where you jot commitments yourself; Leif moves each one into the list with a due date. |
| Einar | Einar | Run entries, the **Deadlines** table (subject, item, due date, status) and the **Work** table for work tasks and deadlines. |
| Askeladd | Askeladd | Run entries, with the full venture metrics table below each one. |
| Thors | Thors | Run entries covering goals, event countdowns, owner follow-ups and membership. |
| Canute | Canute | Run entries, with the monthly money summary below each one. The only place Canute ever writes. |
| Thorkell | Thorkell | Run entries, with the coming week's three-line plan below each one. |

## Tab entry format

From the charter. Each run appends one entry at the top of the member's tab:

```
Run: YYYY-MM-DD HH:MM
Status: green / yellow / red
Findings: 3 to 5 lines, most important first
Next step: one line
For Leif: one line, or "none"
```
